Questions

Is it safe to let it run Claude on my code?

Runs use Claude Code with --permission-mode bypassPermissions, so Claude can run any command in the ticket's folder without asking first. Only add folders you are happy for Claude to change. With version history (git), each ticket works in its own copy of the folder, so your main folder isn't touched until you merge.

What leaves my machine?

Your code and prompts go to Anthropic through your own Claude Code, the same as when you use Claude Code yourself. ckanban itself only checks GitHub for updates, shows your Claude plan usage, and talks to GitHub through gh for your pull requests. It has no account, no server of its own and no analytics. Phone notifications, webhooks and bug reports only go out if you turn them on.

What does it cost?

ckanban is free and open source (MIT License). Runs use your own Claude plan or API usage, nothing on top. Each card shows what its runs cost, and huddles stop at a spending limit you set.

Do I need git or GitHub?

No. A board can be a plain folder. Without git the run works in the folder itself and lists every file it changed. gh is only needed for pull requests and their checks.

Can I use it from my phone?

Yes, through Tailscale. Phone access is off until you turn it on with ckanban remote on, and then only your own Tailscale devices can reach the board.

Where is my data kept?

In plain files on your Mac, under ~/.claude-kanban/. The board listens on 127.0.0.1 only, so other computers on your Wi-Fi can't reach it.
