# ckanban UX audit (2026-11-15)

Checked against UI UX Pro Max 2.15.0 (`references/quick-reference.md` rule ids, `references/pro-rules.md` pre-delivery checklist) and `MASTER.md` in this folder. Screens were checked at 390x844 and 1280x800, light and dark: the before screenshots are in `../before/` (24 files) and `../before/extra/` (52 files), and the code is `web/src` at commit fabda37. Sizes and contrast come from measurements of the live board (headless Chromium, read-only).

Rows are sorted worst first within each batch. Builders: the evidence (file:line, screenshot) is at the end of each fix. "Token" means the fix lands with the design-system step, not the batch. Nothing here changes stored data or its format.

**Status (2026-11-15, design-system step):** fixed A07, A08, A18, A22, A29, A30, A31, C19, C20 (marked ✅); A10 partly (◐, token only). A13 (status colour tokens) is left for batch A. `styles.css:NNN` references are from commit fabda37; the token sweep moved most lines.

Batches: **A** board, columns, cards, top bar, menus · **B** ticket chat, Ask, Tasks, Plan, Outputs, message box · **C** dialogs, settings windows, forms, empty and loading states, toasts.

## Five worst

1. **C01**: settings windows (Automations, Board settings, Schedules, Connections, Team) silently drop unsaved edits on ×, Esc, swipe, Back or picking another item.
2. **C02 + B06**: on phones, about nine fields are under 16px (New ticket description, Schedules, Board settings folder, Bug report, Snippets, question answers, Outputs filter, queued message edit), so iPhone zooms in on every tap.
3. **B05**: on phones, Stop sits 4px from Send while a run goes, and one mis-tap stops the run.
4. **B01**: on phones, a main ticket whose tasks are still running says green "Ready for review", while the board says In Progress.
5. **B07**: on phones, the chat and Ask message boxes don't fit to the iOS keyboard and can end up under it.

## Behaviour changes proposed (one line each)

- A02: the phone More sheet becomes a real dialog: focus moves in and stays, swipe down closes it, focus returns to More.
- A06: the phone Board tab reopens the same column and scroll position after visiting Now, Ask or Team.
- A26: the "Has PR" filter chip only shows on boards where a ticket has an open PR.
- B01: a main ticket whose tasks are running says "Working on tasks" on the phone instead of "Ready for review".
- B02: screen readers hear a reply once when it finishes, not every chunk while it streams.
- B04: Enter that confirms a word on a Japanese or Chinese keyboard no longer sends the message.
- B05: on the phone, the icon-only Stop ignores taps for 800ms after it appears and sits further from Send.
- B10: "Make it its own work" offers Undo (or asks first) instead of acting at once.
- B13: a question option's full description can be opened without picking that option.
- B21: the tool card's Copy shows an error when copying fails instead of "Copied".
- B22: the open ticket tab and file go into the link, so reloads and shared links reopen them.
- C01: closing a settings window, picking another automation or going back with unsaved edits asks "Discard changes?".
- C04: Cancel in Bug report and Board settings asks the same discard question as × and Esc.
- C07: phone error toasts stay until closed (or tap to expand) instead of vanishing after 8s cut to 2 lines.
- C08: Board settings Save is disabled while the chat-size field is invalid, or a blocked Save jumps to that field.
- C09: teammate Delete asks first; removing a note, device or browser offers Undo.
- C11: a failed or slow settings window load shows Retry, with "taking longer than usual" after about 15s.
- C12: Find links becomes a normal dialog with ×, phone sheet, swipe and Back to close, a visible wait and Retry.
- C25: Delete board stays disabled until you type the board name.
- C26: the cron field shows its error only after you leave it, not while typing.
- C29: Connections and Automations tabs move with the Left and Right arrow keys.
